# Demo profil Couvée Palagan

Situs statis multi-halaman berbahasa Indonesia untuk mengenalkan Couvée Palagan (To-Go Store), cabang yang tercantum di situs resmi Couvée di kawasan Sariharjo, Ngaglik.

## Halaman
- `index.html` — beranda
- `menu.html` — pilihan menu (nama dan kategori dari situs resmi)
- `cerita.html` — cerita brand berdasarkan halaman resmi
- `lokasi.html` — alamat, jam buka yang tercantum, peta Google Maps, dan petunjuk arah

## Terbit
Situs ini diterbitkan dengan GitHub Pages dari branch `main`, folder `/(root)`.

## Catatan riset
Saat pengecekan, situs resmi Couvée mencantumkan cabang Palagan di Jl. Kranji, Randuguang, Sariharjo, Ngaglik, dengan jam buka 09.00–22.00. Alamat ini bukan Jl. Umbul Permai. Informasi menu, jam, dan cabang dapat berubah; cek kembali sumber resmi sebelum digunakan sebagai informasi operasional.
