# Demo Codex: daftar tugas

Situs statis berbahasa Indonesia dengan daftar tugas sederhana. Data disimpan di browser perangkat Anda menggunakan localStorage.

## Terbitkan dengan GitHub Pages

1. Buat repository baru di GitHub, misalnya `demo-codex-github`.
2. Unggah isi folder ini (`index.html`, `style.css`, dan `script.js`) ke repository, langsung di folder utama.
3. Buka **Settings → Pages** pada repository.
4. Di bagian **Build and deployment**, pilih **Deploy from a branch**, pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
5. Tunggu beberapa menit. GitHub akan menampilkan tautan situs pada bagian Pages, biasanya `https://NAMA-ANDA.github.io/demo-codex-github/`.

Setelah itu, perubahan file di branch `main` akan diterbitkan ulang otomatis.
